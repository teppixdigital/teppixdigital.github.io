# OAuth vs OIDC vs SAML

- OAuth is an authorization framework. Access to a protected resource is delegated without require sharing the credential.

- OIDC is a verification framework. It's built on top of the OAuth. It verify who the user is. It issues an ID token and access token

- SAML is an enterprise single-sign-on (SSO). User sign-on only once and able to access to all application of enterprise
